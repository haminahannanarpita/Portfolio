# Hamina Hannan — Web Developer Portfolio

A responsive React + Vite portfolio with a dark visual theme, subtle motion, project showcase, skills, leadership experience, and contact links.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Build for deployment
Run `npm run build`. The production site will be generated in `dist/`.

## Before publishing
- Confirm the BDProperties project description and update it if its features differ.
- The two project links currently use the Vercel dashboard URLs supplied. For public visitors, replace them with each app's public deployment URL (usually `*.vercel.app`).
- Add your deployed BDProperties URL when it is available.
- Add your real profile photo or CV link if you want those included.
